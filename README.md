# ローカル完結型 会議録音・文字起こしツール

**会議の議事録を、音声を一切外部に出さずに作る Windows ツールです。**

クラウドの文字起こしに音声を送ると、そこには自分だけでなく**相手の声も含まれます**。
社外に出せない話をしている時、それは選びにくい。このツールは録音から文字起こしまで
手元の PC だけで完結させます。

- **完全ローカル** — 通信するのは初回のモデル取得だけ。以降は回線を切っても動きます
- **話者が正確** — 相手（PC の音）と自分（マイク）を別ファイルに録るので、
  声質からの推測ではなく確定します
- **会議ツールを問わない** — OS のオーディオ機能で音を取るため、
  Zoom / Google Meet / Teams のどれでも同じです

CPU で動きます。60 分の会議で 30 分〜1 時間かかります。

---

## 録音するときのお願い

このツールは **PC で再生されている音声すべて**、つまり**相手の発言も**記録します。

- **録音することを参加者に伝えてください。** 多くの会議ツールには録画通知の仕組みが
  ありますが、このツールは OS 側で音を取るためそれが働きません。**黙って録れてしまう**
  ということは、伝える責任がこちら側にあるということです。
- **地域や職場によっては、同意のない録音に法的・規程上の制約があります。**
  ご自身の状況をご確認ください。
- 録音・文字起こしの結果には、**他人の発言が含まれます**。取り扱いにご注意ください。

## 導入手順

1. [最新版の ZIP](https://github.com/Yu-7777/local-meeting-transcriber/releases/latest)
   をダウンロードする
2. ZIP を右クリック →「**すべて展開**」
3. 中の **`setup.bat` を右クリック → プロパティ →「許可する」にチェック → OK**
4. **`setup.bat` をダブルクリック**して、`Setup complete` が出るまで待つ
   （初回のみ数分〜数十分）
5. Windows キーを押して「**会議**」と入力 → Enter

以上です。**Python などの事前準備は要りません。**

- 手順 3 を飛ばすと「安全でない可能性のあるファイルをブロックしました」と出ます
  → 手順 3 をやってからもう一度 `setup.bat` を実行してください
- 手順 4 の途中で `Put a shortcut on the desktop too? [Y/N]` と聞かれます
  → デスクトップにアイコンが欲しければ `Y`、不要なら `N`（放置でも先へ進みます）

初回に約 2GB を取得します。`setup.bat` は Python 本体（無ければ公式インストーラを
取得、約 25MB、管理者権限は不要）、依存パッケージ（約 350MB）、音声認識モデル
（**約 1.6GB**）を導入します。既に Python 3.10〜3.13 が入っていれば、それを使います。
なぜこの形なのかは [BUILD.md](BUILD.md) にあります。

## 使い方

スタートメニューの `会議録音・文字起こし`、または `gui.bat` から起動します。

1. **相手 / 自分**のデバイスを選ぶ（★既定 のままで大抵合っています）
2. **録音開始** → 会議 → **停止**
3. **文字起こしを実行**（結果はテキストファイルに出ます）

**録音中は両方のメーターが振れていることを必ず確認してください。**
振れていなければデバイス選択が誤っています。ここだけは失敗すると
やり直しがききません。

| 画面の項目 | 補足 |
|---|---|
| 録音を停止したら、そのまま文字起こし | 会議後に放置しておけば議事録ができています |
| 言語 | 既定は日本語。**英語の会議は必ず切り替えてください**（無関係な日本語が出ます） |
| 相手を話者ごとに分ける | 相手が複数人の時に `話者1` `話者2` を付けます。人数は自動推定です |
| 削除 | 録音を**ごみ箱へ**移します（元に戻せます） |
| 出力先 | 録音とは別の場所を指定できます。録音を消しても議事録が残ります |

文字起こし中もウィンドウは操作できます。進捗は下部に出ます。

| モデル | 60 分の会議 | 用途 |
|---|---|---|
| `large-v3-turbo`（既定） | 30 分〜1 時間 | 通常はこちら |
| `large-v3` | 1.5〜3 時間 | 精度最優先。就寝中に回す想定 |

無音が多い会議ほど速く終わります（無音は自動で除去されます）。

<details>
<summary>ショートカットを作り直す / デスクトップにも置く</summary>

```
rem スタートメニューのみ
.venv\Scripts\python.exe shortcut.py

rem デスクトップにも置く
.venv\Scripts\python.exe shortcut.py --desktop
```

デスクトップのアイコンが不要になったら普通に削除するだけです。
</details>

## 最初の録音の前に

1. **音声出力デバイスを録音中に切り替えないでください。**
   Bluetooth の接続・切断などでループバックが途切れます。会議前に固定してください。

2. **PC の音がすべて入ります。** 通知音・BGM・他アプリの音も記録されます。
   会議中は通知をオフにすることを推奨します。

3. **ヘッドフォンを使ってください。** スピーカーだと相手の声がマイクにも回り込み、
   両方のチャンネルに同じ発言が二重に出ます。

4. **Bluetooth ヘッドセットは音質が落ちることがあります。**
   会議アプリがハンズフリー（HFP）に切り替えるとマイク音質が大きく低下し、
   文字起こし精度に直結します。有線か PC 内蔵マイクが確実です。

5. **初回はマイクの許可を求められます。** 押すまでの間の自分の声は録音されません。
   会議前に一度短く録音して、許可を済ませておくと確実です。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| `setup.bat` がブロックされる | 右クリック → プロパティ → **許可する** にチェック（[導入手順](#導入手順)の手順 3） |
| それでもブロックされる | `setup.bat` をもう一度実行してください。評価の確認が間に合っていないだけのことがあります |
| メーターが片方しか振れない | デバイス選択を見直してください。`.venv\Scripts\python.exe app.py devices` で一覧が出ます |
| 「取りこぼしの可能性」と出た | 途中で音が欠けたおそれがあります。他アプリの負荷を下げて録り直してください |
| 英語の会議なのに変な日本語になる | 画面の「言語」を英語に切り替えてください |

### スマート アプリ コントロール (SAC)

ブロックの正体は **スマート アプリ コントロール (SAC)** です。署名のない未知の
コードを実行させない機能で、Windows 11 をクリーンインストールした環境でのみ
有効になります。**個別に許可する仕組みはありません。**
仕組みと、依存パッケージをすべてバージョン固定している理由は
[BUILD.md](BUILD.md) にあります。

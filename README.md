# ローカル完結型 会議録音・文字起こしツール

**自分が参加した会議の議事録を、音声を一切外部に出さずに作るための Windows ツールです。**

会議の音声をクラウドの文字起こしサービスに送ると、そこには自分だけでなく
**相手の声も含まれます**。社外に出せない話をしている時に、それは選びにくい。
このツールは録音から文字起こしまでを手元の PC だけで完結させます。

- **完全ローカル**: 音声も文字起こし結果も外部に送信されません。ネットワークを使うのは
  **初回のモデル取得のみ**で、以降は `--offline` で完全に遮断できます。
- **文字起こし**: faster-whisper (CTranslate2) を CPU で実行します。GPU は不要です。
- **話者が正確**: 相手の声（PC の出力）と自分の声（マイク）を**物理的に別ファイルへ録る**ため、
  声質からの推測ではなく確定します。取り違えが起きません。

Windows のオーディオ機能（WASAPI ループバック）で PC の出力音声を取得する方式なので、
Zoom / Google Meet / Teams など**会議ツールの種類を問わず同じように動きます**。

## 録音するときのお願い

このツールは **PC で再生されている音声すべて**、つまり**相手の発言も**記録します。

- **録音することを参加者に伝えてください。** 多くの会議ツールには録画通知の仕組みが
  ありますが、このツールは OS 側で音を取るためそれが働きません。**黙って録れてしまう**
  ということは、伝える責任がこちら側にあるということです。
- **地域や職場によっては、同意のない録音に法的・規程上の制約があります。**
  ご自身の状況をご確認ください。
- 録音・文字起こしの結果には、**他人の発言が含まれます**。取り扱いにご注意ください。

## セットアップ

### 1. 展開する

**PowerShell に次の 1 行を貼り付けてください。**

```powershell
Expand-Archive ~\Downloads\local-meeting-transcriber.zip -DestinationPath ~\Desktop
```

（ファイル名とバージョンは実際のものに合わせてください）

<!-- エクスプローラーの「すべて展開」だけが Mark of the Web を中身へ伝播させる。
     Expand-Archive は伝播させないので、この 1 行で問題自体が発生しない。 -->
**エクスプローラーの「すべて展開」を使う場合は、先に一手間が必要です。**
ZIP を右クリック → **プロパティ** → 下部の**「許可する」にチェック** → OK、
そのあとで展開してください。

> **なぜこの操作が要るのか**
>
> インターネットから落としたファイルには「Web 由来」の印が付きます。
> エクスプローラーで展開すると**中の全ファイルに伝播**し、その状態の `.bat` は
> スマート アプリ コントロールに
> **「Web からの危険なファイル拡張子」として確実にブロック**されます
> （「安全でない可能性のあるファイルをブロックしました」と表示されます）。
>
> `Expand-Archive` は印を伝播させないので、上の 1 行なら何もせずに済みます。
> `git clone` で取得する場合も印が付かないため不要です。
>
> **既に展開してしまった場合**は、展開先で PowerShell を開いて次を実行すれば
> 直せます。
> ```powershell
> Get-ChildItem -Recurse -File | Unblock-File
> ```

### 2. setup.bat を実行する

`setup.bat` をダブルクリック（または実行）してください。**事前に必要なものはありません。**

1. Python を探す。無ければ公式インストーラを取得して導入（約25MB、管理者権限は不要）
2. `.venv` を作成
3. 依存パッケージを導入（約350MB）
4. 音声認識モデルを `models/` に取得（**約1.6GB**、回線によっては数十分かかります）

既に Python 3.10〜3.13 が入っていれば、それをそのまま使います（新たに入れません）。

**取得するのは既定のモデル（`large-v3-turbo`）だけです。** 精度優先の
`large-v3`（2.9GB）は、初めて選んだ時にその場でダウンロードします。
GUI では未取得のモデルを選ぶと注記が出て、実行前に確認を求めます。
先に取っておきたい場合は次を実行してください。

```
.venv\Scripts\python.exe download_models.py large-v3
```

> **なぜ公式インストーラなのか**
> Python 本体には **PSF の署名**が付いており、スマート アプリ コントロールを
> 通過します。uv などが配布するサードパーティ製の Python は署名がなく、
> 実測で `_ssl.pyd` がブロックされて動作しませんでした。

## 使い方（GUI）

セットアップ時に**スタートメニュー**へ `会議録音・文字起こし` が登録されます。
**Windows キーを押して「会議」と打てば**起動できます。

デスクトップにアイコンを置くかどうかはセットアップ中に聞かれます（既定は
置きません。デスクトップに何も並べたくない人が一定数いるためです）。
15 秒で自動的に「置かない」で進むので、放置しても止まりません。

`gui.bat` のダブルクリックでも同じです。あとから作り直したい場合や、
フォルダを移動した場合は次を実行してください。

```
rem スタートメニューのみ
.venv\Scripts\python.exe shortcut.py

rem デスクトップにも置く
.venv\Scripts\python.exe shortcut.py --desktop
```

デスクトップのアイコンが不要になったら、**普通に削除するだけ**です
（ショートカットなので、消してもツール本体には影響しません）。

```
┌─ 録音 ────────────────────────────────┐
│  相手 (PC の音): [出力デバイス  ★既定 ▼]│
│  自分 (マイク) : [入力デバイス   ★既定 ▼]│
│  名前 (任意)   : [定例MTG              ]│
│  [x] 録音を停止したら、そのまま文字起こし │
│                                        │
│  [ ● 録音開始 ]   00:12:34   録音中     │
│  相手 ▓▓▓▓▓▓▓░░░░░░   -12.8 dB          │
│  自分 ▓▓▓░░░░░░░░░░   -39.3 dB          │
├─ 文字起こし ──────────────────────────┤
│  対象の録音: [2026_08_02_17_29 ▼][更新][改名][削除]│
│  出力先    : [（入力と同じ場所）][変更][既定]│
│  モデル    : [large-v3-turbo         ▼]│
│  [ ] 相手を話者ごとに分ける  人数:[自動▼]│
│  [ 文字起こしを実行 ]  [ 出力先を開く ] │
├─ ログ ────────────────────────────────┤
│  録音開始: 20260802_172942             │
│  完了しました。transcript.txt を…      │
└────────────────────────────────────────┘
```

- 録音中は**両方のメーターが振れているか**を必ず確認してください。
- 文字起こしは時間がかかりますが、その間もウィンドウは操作できます（進捗が下部に出ます）。
- 結果はファイル出力です。「出力先を開く」でフォルダが開きます。

**「録音を停止したら、そのまま文字起こし」** にチェックを入れておくと、停止した
時点で文字起こしまで自動で走ります。会議が終わったら放置しておけば、戻ってきた
頃には議事録ができています。設定は記憶されます。

**「削除」** は選択中の録音を**ごみ箱へ移します**（完全削除ではないので元に戻せます）。
サイズと、消える文字起こしファイルを確認してから実行します。録音中・文字起こし中は
実行できません。

> 録音は消したいが議事録は残したい、という場合は「出力先」を録音とは別の場所に
> 設定してください。そうすれば録音フォルダを削除しても議事録は残ります。

以下は同じことをコマンドラインで行う場合の手順です。

## 使い方（コマンドライン）

### 1. デバイスを確認する（初回・機器を変えた時）

```
.venv\Scripts\python.exe check_devices.py
```

「ループバックデバイス」と「入力デバイス（マイク）」の index を確認します。

### 2. 録音する

会議を始める前に実行します。

```
record.bat
```

または明示的にデバイスを指定する場合:

```
.venv\Scripts\python.exe record.py --mic 24
```

録音中は 2 チャンネルのレベルメーターが表示されます。
**両方のバーが振れていることを必ず確認してください。**
振れていなければデバイス選択が誤っています。

停止は **Enter キー**（Ctrl+C でも可）。
`recordings\日時\` に `system.wav`（相手）と `mic.wav`（自分）が保存されます。

主なオプション:

| オプション | 説明 |
|---|---|
| `--mic <index>` | マイクを指定（既定＝Windows の既定入力） |
| `--loopback <index>` | ループバック元を指定（既定＝Windows の既定出力） |
| `--name <名前>` | 録音に名前を付ける（フォルダ名が `日時_名前` になる） |
| `--seconds <N>` | N 秒で自動停止 |
| `--outdir <path>` | この回だけ保存先を変える |

### 録音の名前

録音フォルダは `2026_08_05_14_30` のように**日時**で作られます。GUI の
「名前」欄（または `--name`）に入れると `2026_08_05_14_30_定例MTG` になります。

日時を先頭に置いているのは、名前順に並べた時に時系列順になるためです。
後から GUI の「改名」ボタンで名前だけを付け替えられます（日時は変わりません）。
録ってから名前を決めても問題ありません。

- Windows で使えない文字（`\ / : * ? " < > |`）は `_` に置き換えます
- 同じ分に録り直した場合は `_2` `_3` と連番が付き、**前の録音を上書きしません**

**保存先の既定は `config.json` に記憶されます。** GUI の「保存先」欄で
「変更」を押すと、次回以降もそこに保存されます（1 時間の会議で約 1.3GB
使うので、容量に余裕のあるドライブを指定できます）。

**録音の保存先と、文字起こしの出力先は別々に指定できます。**
録音（GB 単位・使い終わったら消す）と議事録（KB 単位・残す）は
性質が違うため、たとえば「録音は外付けドライブ、議事録は同期フォルダ」
といった分け方ができます。詳細は次節。

### 3. 文字起こしする

録音とは別に、後から実行します（CPU 処理のため時間がかかります）。

```
.venv\Scripts\python.exe transcribe.py
```

引数なしで**最新の録音**を処理します。対象は自由に指定できます。

```
rem 特定の録音フォルダ
.venv\Scripts\python.exe transcribe.py recordings\2026_08_05_14_30_定例MTG

rem 手元の音声ファイルを直接（IC レコーダーの録音なども可）
.venv\Scripts\python.exe transcribe.py "D:\会議\打ち合わせ.mp3"

rem 出力先を分ける
.venv\Scripts\python.exe transcribe.py "D:\会議\打ち合わせ.mp3" --outdir "D:\議事録"
```

対応形式は wav / mp3 / m4a / flac / ogg / aac / wma と、mp4 / mkv / webm / mov
（動画から音声を取り出します）。

単体ファイルを指定した場合、結果は `<元のファイル名>_transcript.txt` として
出力されます。話者は「自分／相手」に分けられないため、`--diarize` を付けた時のみ
`話者1` `話者2` が付きます。

GUI では「音声ファイルを選ぶ...」ボタンから同じことができます。

主なオプション:

| オプション | 既定 | 説明 |
|---|---|---|
| `--model` | `large-v3-turbo` | `large-v3` にすると精度が上がるが数倍遅い（初回のみ 2.9GB の取得あり） |
| `--language` | `ja` | `auto` で自動判定、`en` で英語 |
| `--threads` | `4` | CPU スレッド数 |
| `--outdir` | 設定値 | 出力先。未設定なら入力と同じ場所 |
| `--offline` | off | 取得済みモデルのみ使用（ネットワークに一切触れない） |
| `--diarize` | off | 相手側を声質で話者ごとに分ける（相手が複数人の時） |
| `--speakers` | 自動 | 相手側の人数。指定すると分離精度が上がる |

出力は `transcript.txt` の 1 ファイルだけです。

```
[00:00:03] 相手: 本日はお時間いただきありがとうございます。
[00:00:08] 自分: よろしくお願いします。
```

### 出力先を録音とは別の場所にする

既定では録音フォルダの中に出力しますが、GUI の「出力先」欄（または
`--outdir`）で別の場所を指定できます。指定は `config.json` に記憶され、
「既定」ボタンで元に戻せます。

**出力先を録音フォルダの外にすると、ファイル名に録音名が前置きされます。**

```
録音フォルダ内（既定） : transcript.txt
別の場所を指定した場合 : 2026_08_05_14_30_定例MTG_transcript.txt
```

すべての録音が `transcript.txt` という同じ名前で出ると、同じフォルダに
まとめた時に**先に作ったものが上書きされて消える**ためです。
単体ファイルを指定した場合も同様に `<元のファイル名>_transcript.txt` になります。

優先順位は **`--outdir` > `config.json` の設定 > 入力と同じ場所** です。

### 4. 相手が複数人いる場合（話者分離）

`自分` と `相手` はデバイスで物理的に分かれているため常に正確ですが、
相手側に複数人いると全員が `相手` にまとまります。
`--diarize` を付けると、相手チャンネルを声質で話者ごとに分けます。

```
.venv\Scripts\python.exe transcribe.py --diarize --speakers 3
```

```
[00:00:00] 相手(話者1): お疲れさまです。それでは定例を始めます。
[00:00:09] 相手(話者2): こちらは認証まわりの実装が終わりまして、今テスト環境で確認しています。
[00:00:18] 相手(話者1): ありがとうございます。何か懸念点はありますか。
[00:00:23] 自分: レート制限の件、こちらでも確認しておきます。
```

**まず自動のまま試してください。** `--speakers` での人数指定は必須ではなく、
実測では**指定しないほうが良い結果**でした（下記）。

| オプション | 既定 | 説明 |
|---|---|---|
| `--speakers N` | 自動 | N 人ちょうどに強制。自動が外れた時だけ使う |
| `--diar-threshold` | `0.9` | 大きいほど統合が進み**人数が減る**。小さいと増える |

**チューニングの実測データ**（YouTube の 3 人の対談・5 分で計測）

| threshold | 検出人数 | 内訳 |
|---|---|---|
| 0.5（旧既定） | **25 人** | 104s 54s 47s 35s 11s 6s … +1秒未満が8個 |
| 0.7 | 14 人 | 117s 107s 33s 15s … |
| **0.9（現在の既定）** | **3 人** | **125s / 118s / 48s** |
| `--speakers 3` 強制 | 3 人 | 167s / 126s / 3s ← 2 人分が融合して悪化 |

閾値 0.9 に加えて、**合計発話が 3 秒未満のクラスタは自動的に除外**します
（BGM・効果音・場面転換の音質差が「話者」として数えられるのを防ぐため）。

**精度について正直な注意**

- 会議音声はコーデック圧縮とノイズ抑制で劣化しているため、**取り違えは起こります**。
  特に発言の被り、相槌、ごく短い返事に弱いです。確定情報ではなく参考情報として扱ってください。
- 人数が実態と合わない時は `--diar-threshold` を 0.05 刻みで調整するのが有効です。
  それでも合わなければ `--speakers` で強制してください。
- 出せるのは `話者1` `話者2` という区別までで、**実名は出せません**。
- `自分` 側は分離不要なので処理しません。そのぶん一般的な話者分離より条件は良好です。

## 処理時間の目安

このツールはリアルタイム処理をしません。CPU（NVIDIA GPU 非搭載機）での目安:

| モデル | 60 分の会議の処理時間 | 用途 |
|---|---|---|
| `large-v3-turbo`（既定） | 概ね 30 分〜1 時間 | 通常はこちら |
| `large-v3` | 概ね 1.5〜3 時間 | 精度最優先。就寝中に回す想定 |

この PC での実測値（短いサンプル）は turbo が実時間の約 2.4 倍速、
large-v3 が約 1.1 倍速でした。2 本のファイルを順に処理するため、
上表はその合計です。

会話では各チャンネルの半分以上が無音になるため、VAD（無音除去）が効いて
実際にはこれより短く終わることが多いです。逆に発言が途切れなく詰まっている
録音では上表より長くかかります。

## 注意点・既知の制約

1. **録音中に音声出力デバイスを切り替えないでください。**
   Bluetooth ヘッドセットの接続・切断などを行うとループバックが途切れます。
   会議前にデバイスを固定してから録音を開始してください。

2. **ループバックは PC の音すべてを拾います。**
   通知音・BGM・他アプリの音も入ります。会議中は通知をオフにすることを推奨します。

3. **ヘッドフォン／イヤホンの使用を推奨します。**
   スピーカーで再生すると相手の声がマイクにも回り込み、両チャンネルに同じ発言が
   二重に出ます。ヘッドフォンなら分離がクリーンになります。

4. **Bluetooth ヘッドセットは音質が落ちる場合があります。**
   会議アプリがハンズフリー（HFP）モードに切り替えるとマイク音質が大きく低下し、
   文字起こし精度に直結します。可能なら有線ヘッドセットか PC 内蔵マイクを推奨します。

5. **初回はマイクへのアクセス許可を求められます。**
   Windows のダイアログで「許可」を押すまで、マイクは音を返しません。
   **押すまでの間の自分の声は録音されません**（時間軸は無音で埋められるため、
   トランスクリプトの時刻はずれません）。
   一度許可すれば以降は出ないので、初回だけ会議開始前に短く録音して
   許可を済ませておくと確実です。

6. **デバイスの起動遅延は自動補正されます。**
   USB マイク等は録音開始から数秒遅れて音を返し始めることがあります。
   本ツールは遅延分の無音を先頭に詰めて 2 本の WAV を同一時間軸に揃えるため、
   トランスクリプト上の時刻がずれることはありません。

7. 録音終了時に表示される「ズレ」が大きい（±2 秒超）場合は、途中で音を取りこぼした
   可能性があります。その場合は他アプリの負荷を下げて再試行してください。

8. **「アプリケーション制御ポリシーによってこのファイルがブロックされました」と出た場合**
   （Windows セキュリティの通知も併せて飛んできます）

   **スマート アプリ コントロール (SAC)** による ブロックです。SAC は
   Windows 11 を**クリーンインストール**した環境でのみ有効になる機能で、
   バイナリを読み込むたびに次のどちらかを満たすか検査します。

   - Microsoft のクラウド評価が「安全」と判定している
   - Trusted Root Program の CA が発行した証明書で署名されている

   どちらも満たさない「**未知かつ署名なしのコード**」はブロックされます。
   **個別に許可する方法は用意されていません**（Microsoft の FAQ に明記）。

   **最も多いのは `.bat` のブロックです。** ダウンロードした ZIP をそのまま
   展開すると「インターネット由来」の印が全ファイルに伝播し、SAC が
   `setup.bat` や `gui.bat` を弾きます。これは上の「セットアップ 0.」で
   解決します（ZIP を展開前に「許可する」）。

   このツールの依存パッケージには署名のないネイティブ DLL が多数含まれるため、
   本来この機能と相性が良くありません。対策として `requirements.txt` で
   **推移的な依存まですべてバージョンを固定**し、SAC が有効な Windows 11 で
   動作を確認済みの組み合わせだけを使うようにしています。固定を外して
   新しいバージョンを引くと、評価が付いていないためブロックされることがあります。

   それでもブロックが出た場合は、まず `setup.bat` を再実行してください
   （評価の確認が間に合っていないだけのことがあります）。
   自分の PC で SAC が有効かどうかは、Windows セキュリティ →
   「アプリとブラウザーの制御」に「スマート アプリ コントロール」の項目が
   あるかどうかで分かります。項目が無ければ対象外です。
